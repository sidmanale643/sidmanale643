## Projects

### [Ares](https://github.com/sidmanale643/Ares)

A terminal-first coding agent with a persistent Python workspace, process-isolated subagents, progressive skills, local JSONL and SQLite sessions, and a full-screen TypeScript terminal UI.

### [Evalon](https://github.com/sidmanale643/evalon)

Local observability and evaluation for Python agents. Trace runs in SQLite, turn reviewed traces into versioned datasets, and run deterministic, Python, or rubric-based evaluations.

### [Atlas](https://github.com/sidmanale643/Atlas)

A Python semantic-memory framework with SQLite storage, optional LanceDB vector search and local embeddings, plus optional CLI, API, MCP, and web adapters.

### [CurseBench](https://github.com/sidmanale643/cursebench)

Read-only, local-first telemetry for abusive language in coding-agent sessions. Compare harnesses without exporting chat data and measure a normalized Curse Energy metric.

### [Terminus CLI](https://github.com/sidmanale643/terminus-cli)

An AI coding agent for the terminal that explores codebases, plans and edits changes, runs commands, and keeps durable local session history.

### [Bloom](https://github.com/sidmanale643/bloom)

An agent-run Obsidian knowledge vault that turns videos, papers, web content, PDFs, screenshots, and notes into linked source notes and synthesized research.
